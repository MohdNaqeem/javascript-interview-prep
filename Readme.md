# JavaScript Interview Preparation

A focused, hands-on repository for mastering JavaScript fundamentals, output-based reasoning, and machine coding — built for technical interview and machine round preparation.

> 📌 This is a **practice/learning repository**. For my main project work, see **[TrackHire](https://github.com/MohdNaqeem/TrackHire)** — a full-stack MERN job application tracker.

The goal isn't memorizing interview answers — it's building real fluency: understanding *why* JavaScript behaves the way it does, predicting output correctly under pressure, and implementing common UI patterns from scratch without relying on a library.

## 🎯 Focus Areas

### JavaScript Fundamentals
- Variables, Data Types & Type Coercion
- Scope & Lexical Scope
- Hoisting
- Functions & Higher-Order Functions
- Closures
- `this` Keyword
- Objects & Prototypes / Prototype Chain
- Arrays & Array Methods
- Destructuring, Spread & Rest
- Call, Apply & Bind
- Execution Context & Call Stack
- Event Loop & Asynchronous JavaScript
- Promises & Async/Await
- ES6+ Features
- Error Handling

### Output-Based Questions
Predicting execution order and output for tricky JS snippets — hoisting edge cases, closures inside loops, `this` binding pitfalls, and async/microtask-vs-macrotask ordering. Each solved problem includes the code, my predicted output, and a short explanation of *why*.

### Machine Coding
Implementing common frontend interview problems from scratch, without libraries:
- Debounce & Throttle
- Polyfills for `map`, `filter`, `reduce`, `bind`, `call`, `apply`
- Custom Event Emitter / Pub-Sub
- Small UI components under time pressure (e.g. accordion, modal, tabs, infinite scroll)
